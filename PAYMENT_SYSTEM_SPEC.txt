3. USER FLOW
================================================================================

STEP 1: User Order
-------------------
User mengirim invite link grup ke bot via private chat.
Format: https://chat.whatsapp.com/XXXXXXXXXX

STEP 2: Bot Validation
-----------------------
Bot melakukan validasi:
1. Extract invite code dari link
2. Query group info via client.group.queryGroupInviteInfo(code)
3. Check requirements:
   - Grup tidak penuh (size < 1024 member)
   - Grup buka/open (tidak perlu approval admin)
   - Invite code masih valid (tidak expired/revoked)

STEP 3: Generate Payment
-------------------------
Jika validasi OK:
1. Create order di database (status: pending)
2. Request deposit via CiaaTopUp API
   - Endpoint: POST /v1/deposit
   - Body: { merchantId, secretKey, nominal: 10000 }
   - Response: { orderId, total, qrDataUri }
3. Send QRIS ke user dengan info:
   - Nama grup
   - Total pembayaran (Rp 10.000 + admin fee)
   - Order ID
   - Expire time (biasanya 15-30 menit)

STEP 4: User Payment
---------------------
User scan QRIS dan bayar via DANA/OVO/GoPay/dll.

STEP 5: Webhook Notification
-----------------------------
CiaaTopUp mengirim webhook POST request ke bot:
URL: https://[DOMAIN-BOT]/webhook/payment
Headers: X-Signature (HMAC-SHA256)
Body: {
  "event": "deposit.status",
  "orderId": "DEP-1710000000000",
  "status": "Paid"
}

STEP 6: Bot Action
------------------
Webhook handler:
1. Verify X-Signature (HMAC-SHA256 dengan secret key)
2. Update order status di database (pending → success)
3. Join grup via client.group.joinGroupViaInvite(code)
4. Send konfirmasi ke user:
   "Bot sudah berhasil join grup [Nama Grup]"
5. Log transaction untuk accounting

STEP 7: Auto-Withdraw
---------------------
Background scheduler (cron job) check saldo CiaaTopUp:
- Interval: Setiap 6 jam atau 12 jam
- Check: GET /v1/profile
- Jika balance >= Rp 20.000:
  1. Request withdraw via POST /v1/transfer/create
     - Bank code: DANA
     - Account: 083809720392
     - Name: Azrial Galih Prasetyo
     - Amount: [saldo - buffer Rp 5.000]
  2. Log withdraw request
  3. Status: Pending (manual approval by CiaaTopUp admin)

-----------------------

- balance_after (INTEGER) - Saldo sesudah
- created_at (INTEGER) - Timestamp

6. WEBHOOK SIGNATURE VERIFICATION
================================================================================

CiaaTopUp mengirim header X-Signature untuk verify request.
Signature: HMAC-SHA256(payload, secretKey)

Verification Code:
------------------
import crypto from 'crypto'

function verifySignature(payload, signature, secretKey) {
  const hash = crypto
    .createHmac('sha256', secretKey)
    .update(JSON.stringify(payload))
    .digest('hex')
  
  return hash === signature
}

Usage:
------
const signature = req.headers['x-signature']
const payload = req.body
const isValid = verifySignature(payload, signature, SECRET_KEY)

if (!isValid) {
  return res.status(401).json({ error: 'Invalid signature' })
}

8. VALIDASI GRUP
================================================================================

Requirements sebelum generate payment:
--------------------------------------
1. Invite code valid (tidak expired/revoked)
2. Grup tidak penuh (member < 1024)
3. Grup buka/open (tidak perlu approval)
4. Bot belum join grup tersebut
5. User belum punya pending order untuk grup tersebut

Error Messages:
---------------
- "Invite link tidak valid atau sudah expired"
- "Grup sudah penuh (1024 member), bot tidak bisa join"
- "Grup memerlukan persetujuan admin, mohon ubah setting grup"
- "Bot sudah ada di grup ini"
- "Kamu masih punya order pending untuk grup ini"

================================================================================
10. ERROR HANDLING
================================================================================

Payment Errors:
---------------
- Timeout: Order expired (15-30 menit)
- Failed: Payment gagal (insufficient balance, dll)
- Expired: QRIS sudah tidak valid

Bot Join Errors:
----------------
- Invite revoked: Code sudah di-rotate admin
- Group full: Grup penuh setelah payment
- Permission denied: Grup setting berubah (butuh approval)
- Already member: Bot sudah di grup (tidak refund)

Webhook Errors:
---------------
- Invalid signature: Reject request
- Duplicate event: Check database, skip jika sudah processed
- Unknown order_id: Log dan skip

Withdraw Errors:
----------------
- Insufficient balance: Minimum tidak tercapai
- Invalid account: Nomor/nama salah
- API error: Retry dengan exponential backoff

11. SECURITY
================================================================================

1. Webhook Signature Verification
   - Always verify X-Signature header

2. API Credentials
   - Store in .env file (not in code)

   - Rotate secret key periodically

3. Database
   - No sensitive data in logs
   - Encrypt payment details if needed
   - Regular backup

4. Rate Limiting
   - Max 3 order per user per hour
   - Max 1 pending order per grup
   - Cooldown 5 menit after failed payment
