# Assets Folder

This folder contains static assets for bot features.

## Watermark Logo

**File:** `watermark.png`  
**Size:** 100x100px (recommended)  
**Format:** PNG with transparent background  

**Used for:** PureStatus media watermark

### How to add:

1. Prepare your logo (100x100px PNG)
2. Save as: `assets/watermark.png`
3. Bot will auto-overlay on downloaded media

### Watermark layout:

```
[LOGO 100x100]
www.sbmku.sbs
```

Position: Bottom-right corner with semi-transparent overlay.
